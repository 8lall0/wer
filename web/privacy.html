wer: privacy policy

Last updated: 7 October 2026.

wer is a Game Boy, Game Boy Color and Super Game Boy emulator, made by 8lall0 (github.com/8lall0/wer). This policy covers the Android app (io.github.eightlall0.wer), the desktop versions, and the web version at 8lall0.github.io/wer.

In short

wer does not collect, store, sell or share any personal data. It has no accounts, no advertising, no analytics and no tracking. Nothing you do in wer is sent to its author or to anyone else.

Your files stay on your device

The games (ROMs) you open, your saves and save states, your settings, cheats, screenshots and Game Boy Printer printouts are kept only on your device (in the web version, only in your browser's storage). wer does not upload them anywhere. wer comes with no games: you load your own.

Permissions (Android)

  • Camera: used only by Game Boy Camera games, and only once you allow it. The picture goes to the emulated camera cartridge, as on the real one, and nowhere else; wer does not record, store or send it. A photo is kept only if you save it in the game or print it with the emulated Game Boy Printer, and then only on your device.
  • Internet: used only for the link cable between two copies of wer, when you start it yourself (Menu → Link). wer then connects directly to the other player's device at the address you enter, and the two exchange only what a Game Boy link cable carries: the bytes the two games send each other. No server of ours is involved.
  • Vibration: for games with a rumble motor.

The web version

The web version is a page served by GitHub Pages; GitHub may keep the usual logs of visits to it (see GitHub's privacy statement). The page itself uses no cookies, analytics or advertising.

Only if you link two browsers with a code (Menu → Link), the page loads the PeerJS library from unpkg.com and uses the public PeerJS server and a STUN server so that the two browsers can find each other; those services see the two devices' network addresses, as any connection does. After that, the game data goes directly between the two browsers.

Children

wer collects no data from anyone, children included.

Changes

If wer ever changes how it handles data, this page will say so first, with a new date above.
